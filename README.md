# avira-apps

Public support and privacy pages for Avira LLC's iPhone apps, served by GitHub
Pages at https://devjq.github.io/avira-apps/. App Store Connect links to them.

- `construction-calc/`: Shim: Construction Calculator. The source copies live in
  the private `construction-calc` repo under `site/`; edit them there, then copy
  them here.

- `surchara/`: Surchara: AI Search Pages (a Shopify app). The privacy and support
  pages are copies of `docs/public/surchara/` in the private `surchara-shopify` repo,
  and `screencast.mp4` is its `docs/listing/screencast.mp4`; edit them there, then copy.

The guides' sources and `build.py` live in the private construction-calc repo under
`site/guides/`; the guide pages here are copies made by that script.

Keep this repo to static pages only, with nothing private in it.
