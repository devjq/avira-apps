# avira-apps

Public support and privacy pages for Avira LLC's iPhone apps, served by GitHub
Pages at https://devjq.github.io/avira-apps/. App Store Connect links to them.

- `construction-calc/`: Shim: Construction Calculator. The source copies live in
  the private `construction-calc` repo under `site/`; edit them there, then copy
  them here.

Keep this repo to static pages only, with nothing private in it.
